# 速查表（无脚本降级路径）

> 本文件由 `scripts/gen_quick_ref.py` 从 additives.json 自动生成（数据库版本 2026.10-v4），供宿主 Agent **无法运行脚本**时降级使用。能用脚本就优先用脚本：`python scripts/scan.py --text "配料表"`。

## 降级评估流程

1. 拿到配料表文本（转写规则见 SKILL.md：只取配料栏、保持顺序、保留括号）。
2. 按逗号/顿号切分顶层配料，括号内的子配料单独切出（复合配料的子项单算，但不占顶层位次）。
3. 逐项在下表查风险级（🟢0/🟡1/🔴2）；查不到且名字像添加剂（以“剂/香精/香料/色素/酯/酸钠/胶…”结尾或为 E 编号）记“未收录疑似添加剂”。
4. 按下方计分表累加得近似狠活指数，对照灯档。
5. 输出时**明确告知**：本次为降级近似评估，建议在有脚本能力的环境复核。

## 口径红线（降级模式同样适用）

- 衡量配料复杂程度，**不是食品安全结论**；禁用“致癌/有毒/绝对不能吃”等断言。
- 未收录 ≠ 有害，如实标注“以包装标注为准”。
- 过敏原按配料名推断的软提示，提醒以包装过敏原标示为准。
- 不虚构国标限量数字，不做针对具体产品的健康建议。
