# 狠活指数评分规则（与 scan.py 实现对齐）

> 设计原则：**确定性、可解释、可复现**。同一份配料表在任何机器上任何时候跑出的分数完全一致；
> 每一分都能在报告"评分明细"里找到来源。评分衡量的是**配料复杂程度**，不是食品安全结论。

## 一、输入信号

| 信号 | 来源 |
|------|------|
| 添加剂总项数 | 解析器识别出的添加剂条目数（含未收录的疑似添加剂） |
| 留意级数量 | 数据库 risk=1 的已收录添加剂 |
| 特别关注级数量 | 数据库 risk=2 的已收录添加剂 |
| 糖类配料位次 | 顶层配料中第一个糖类（kind=sugar）的序位；配料表按国标递减排序，位次≈含量 |
| 反式脂肪风险 | 原料名命中关键字：氢化 / 植脂末 / 人造奶油 / 植物奶油 / 起酥油 / 代可可脂 / 奶精 |
| 亚硝酸盐 | 命中护色剂：亚硝酸钠 / 硝酸钠 / 亚硝酸钾 / 硝酸钾 |
| 未收录疑似添加剂 | 名字像添加剂（以"剂/香精/香料/色素/酯/酸钠/酸钾/酸钙/酐/苷/胶"结尾或 E 编号）但数据库查不到的条目 |

## 二、计分表

| 规则 | 分值 | 上限 |
|------|------|------|
| 添加剂每项 | +2.5 | 20 |
| 留意级（risk=1）每项 | +4 | — |
| 特别关注级（risk=2）每项 | +12 | — |
| 糖类排在第 1–3 位 | +10 | — |
| 糖类排在第 4–5 位 | +5 | — |
| 反式脂肪风险配料 | +20 | — |
| 糖排首位 + 反式脂肪风险（组合红旗） | +5 | — |
| 亚硝酸盐类护色剂 | +8 | — |
| 未收录疑似添加剂每项 | +2 | 6 |

总分四舍五入取整，封顶 100。

## 三、灯档

| 分数 | 灯档 | 口径 |
|------|------|------|
| 0–20 | 🟢 绿灯 | 配料简单干净：以天然原料为主，添加剂少且常规 |
| 21–45 | 🟡 黄灯 | 配料平常：常规工业化食品水平，无明显红旗项 |
| 46–70 | 🟠 橙灯 | 配料偏复杂：添加剂较多或含值得留意的成分，建议权衡频次 |
| 71–100 | 🔴 红灯 | 配料很复杂：添加剂密集且/或含反式脂肪风险、高糖等红旗项 |

## 四、风险分级（数据库 risk 字段）口径

- **0 常规安心**：国标允许、天然来源或长期广泛使用、无普遍人群提示（例：柠檬酸、果胶、维生素C）。
- **1 留意**：正常使用安全，但值得知道它在干什么，或有特定人群提示（例：山梨酸钾、三氯蔗糖、合成色素——欧盟对部分合成色素要求标注儿童注意力提示）。
- **2 特别关注**：合法限量使用，但公众关注度高或场景敏感（例：亚硝酸钠——腌腊工艺必需且与亚硝胺相关；氢化植物油——反式脂肪酸风险；含铝膨松剂——铝残留；脱氢乙酸钠——2024 版国标已收窄使用范围）。

## 五、边界与自检

1. **不做健康断言**：所有"提示"只陈述国标事实与主流科学共识，禁止使用"致癌/有毒/绝对不能吃"等表述。
2. **未收录 ≠ 有害**：数据库是常用子集（v4 共 360 条，条数以 additives.json 的 version 与 CHANGELOG 为准）而非全集，未收录项如实标注"以包装标注为准"，仅轻微计分。
3. **模糊匹配容忍 OCR 错字**（如"苯甲酸纳"→苯甲酸钠，相似度阈值 0.74，另有 3–4 字短词的首字锚定宽松匹配），但宁可标"未收录"也不硬凑。
4. **过敏原为启发式软提示**：按配料名关键字推断，报告注明"以包装过敏原提示为准"。
5. 数据版本随数据库 version 字段标注，规则调整时同步更新本文件。
